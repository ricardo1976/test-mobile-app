# ¿Cuánto recuerdas?

Aplicación Flutter para Android e iOS. La experiencia y el contenido de V0.1
están dirigidos al español de España (`es-ES`). Consulta los documentos de
producto, arquitectura y roadmap en `docs/`.

## Desarrollo

Con Flutter estable instalado y disponible en `PATH`:

```powershell
flutter pub get
flutter analyze
flutter test
flutter run
```

La pantalla actual es una demostración visual. El juego todavía no está activo.
No se necesita backend ni servicio externo para ejecutar este esqueleto.

## Plataformas

- Android: requiere Flutter, Android SDK, Android SDK Command-line Tools y las
  licencias Android aceptadas. Ejecuta `flutter doctor` para revisar el entorno.
- iOS: generar y compilar la aplicación requiere macOS y Xcode. El proyecto
  incluye la configuración iOS, pero este entorno Windows no puede validarla.
