# Roadmap

## V0.1

Initial roadmap for ¿Cuánto recuerdas?.

- Establish Flutter project structure.
- Implement multilingual foundation with Spanish as the default language.
- Implement the initial question model and question bank.
- Implement deterministic daily question selection.
- Implement the core quiz experience.
- Implement results and sharing.
- Prepare the advertising abstraction without integrating AdMob yet.
- Establish automated testing.
- Prepare Android and iOS release foundations.

The roadmap should be updated as product decisions and implementation priorities evolve.
