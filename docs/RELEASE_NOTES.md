# Release Notes - V0.1

## Features
- Daily quiz with 5 questions from 500-question Spanish bank
- Deterministic daily selection
- Local persistence (no accounts)
- Statistics and streak tracking
- History
- Result sharing
- Onboarding
- Spanish (es-ES) localization

## Limitations
- No backend/cloud sync
- No ads in V0.1 (abstraction only)
- Android/iOS builds require platform setup
- Some tests have pre-existing issues unrelated to core functionality

## Verification
- Question bank validated
- CI configured for format/analyze/test/validation
- Core flows implemented and tested
